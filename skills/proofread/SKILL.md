---
name: proofread
description: Use when asked to proofread text.
argument-hint: "<files, directory, or 'staged changes'>"
---

Proofread the provided files and ONLY make minor corrections to grammar or spelling. Keep the author's wording, tone, markdown structure, and line breaks.

Summarize what you changed and why. If there are readability issues, list them out to the user rather than changing the text.
